## Problem
Business-critical client applications ran on on-premises servers with manual deployments, ageing hardware and no tested recovery plan.

## What I did
- Designed the target Azure environment: networking, VMs, web apps, SQL Server workloads.
- Built staging environments mirroring production for testing before each cutover.
- Set up backups and disaster-recovery plans, and tested them.
- Migrated applications and databases in planned windows with minimal downtime.
- Introduced Azure DevOps pipelines and Bicep infrastructure-as-code so environments are reproducible.

## Result
10+ VMs and 5-10 web applications with their SQL Servers running in Azure; little to no downtime during migration; repeatable deployments and documented recovery.
